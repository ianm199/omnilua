# Archive

Dated plans, sprint specs, phase reports, reviews and triage notes from the
May–July 2026 build. They record how decisions were reached and are kept for
history. They are not maintained: paths, issue numbers and status inside them
can be out of date. Nothing outside this folder links here except the
changelog and a few historical notes.

For current behavior, read the code, `CHANGELOG.md` and the GitHub issues.
